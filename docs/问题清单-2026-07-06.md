| ID | 等级 | 位置 | 问题 | 建议修复 |
|---|---|---|---|---|
| SEC-1 | 🔴 严重 | `app.js:65` + `auth.js:71-73` | 后台 `/api/v1/admin/*` 仅挂普通 `authMiddleware`，`adminAuthMiddleware`/`requirePermission` 零接线；`auth.js` demo 放行逻辑允许普通用户 token 访问全部后台 | 后台改挂 `adminAuthMiddleware`，删除 demo 放行，敏感操作叠 `requirePermission` |

| SEC-4 | 🟠 高 | `finance.js` + `app.js:66` | 财务接口仅校验登录未校验 admin 角色，任意用户可读全平台营收、可写流水 | `/finance/*` 接入 `adminAuthMiddleware` + `requirePermission('finance')` |
| SEC-5 | 🟡 中 | `auth.js:107` `/login-guest` | 免密登录直接签发 userId=1 真实会话 | 生产移除，或隔离为演示专用账号 |
| SEC-6 | 🟡 中 | `app.js:9` | `cors()` 通配任意源可读 API | 显式 `origin` 白名单 |
| SEC-7 | 🟡 中 | `app.js:134-137` | 全局错误回吐 `err.message`（含 SQL 片段） | 生产返回固定文案，详情仅记日志 |
| SEC-8 | 🟡 中 | `notification.js:31` | `/notifications/send` 匿名即可向任意用户投递伪造系统消息 | 加 `adminAuthMiddleware`，内容转义 |
| SEC-9 | 🟡 中 | `web/js/api.js` 等三端 + 无 CSP | token 存 `localStorage`，服务端无 CSP | 改 HttpOnly+Secure+SameSite Cookie，或加 `helmet`/CSP |
